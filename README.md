# 🚀 Mini-Projets de Manipulation d'APIs

Ce dépôt regroupe une série de mini-projets web conçus pour s'entraîner à l'interaction avec des APIs externes en JavaScript (Fetch API / Async-Await). Chaque projet permet d'explorer l'affichage dynamique de données en temps réel.

---

## 🛠️ Technologies Utilisées

* **HTML5** : Structure des pages web
* **CSS3** : Mise en page et stylisation
* **JavaScript (ES6+)** : Requêtes HTTP, manipulation du DOM et gestion de l'asynchronisme

---

🌟 Aperçu des Projets
1. 🪙 Crypto Tracker (crypto.html)

    Description : Affiche les cours et informations actuelles sur les cryptomonnaies.

    Concepts clés : Consommation d'API de données financières, mise à jour dynamique des données.

2. 😂 Générateur de Blagues (joke.html)

    Description : Génère des blagues aléatoires à chaque clic sur un bouton.

    Concepts clés : Requêtes GET simples, gestion des réponses JSON.

3. 🎬 Recherche de Films (movie.html)

    Description : Permet de rechercher des films et d'afficher leurs informations (affiches, synopsis, notes).

    Concepts clés : Utilisation de barres de recherche, gestion de paramètres de requête API (ex: TMDB ou OMDb API).
